Sejam bem‑vindos

Todo pixel de uma tela é formado por três luzes. A trava abaixo só se abre quando as luzes são acionadas na ordem do registro:

  1. #00FF00
  2. #0000FF
  3. #FF0000
  4. #00FF00

[ acessar documento ]

Na web, toda cor é escrita como # seguido de três pares de dígitos. O primeiro par é o vermelho, o segundo é o verde e o terceiro é o azul.

FF é a luz no máximo; 00 é a luz apagada. Em cada código do registro, só uma das três luzes está acesa.

Em #00FF00, só o par do meio está aceso: é o verde. Comece por ele.
